# Elevation Fire Protection

Marketing website for [Elevation Fire Protection](https://elevationfireprotection.com) — a Denver-based fire sprinkler contractor serving Colorado and Wyoming.

Built with [Astro](https://astro.build) and Tailwind CSS, hosted on Cloudflare Pages.

## Develop

```sh
npm install
npm run dev   # http://localhost:4321
```

## Build

```sh
npm run build   # outputs to dist/
npm run preview # preview the production build
```

## Deploy

Production deploys via Cloudflare Pages. Pushes to `main` trigger automatic rebuilds.

Manual deploy from local:

```sh
wrangler pages deploy dist --project-name elevation-demo-v2 --branch main
```
